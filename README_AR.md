# تطبيق بطاقات الألمانية — مشروع Android

## بناء APK باستخدام هاتف Android فقط

تم تضمين GitHub Actions لتجميع APK على خوادم GitHub، بينما يمكنك إدارة المشروع من الهاتف.

1. أنشئ مستودعاً جديداً (Repository) على GitHub باسم `DeutschKarten` واجعله Public أو Private.
2. في Termux ثبّت الأدوات:
   `pkg update && pkg install git unzip`
3. نزّل ملف المشروع ZIP إلى مجلد Downloads في الهاتف، ثم فك ضغطه.
4. انسخ محتويات مجلد `DeutschKartenAndroid` إلى مجلد المستودع الذي تستنسخه عبر `git clone`.
5. نفّذ `git add .` ثم `git commit -m "Initial Android app"` ثم `git push`.
6. في GitHub افتح المستودع ثم تبويب Actions. افتح مهمة **Build Android APK** وانتظر نجاحها.
7. افتح نتيجة التشغيل (workflow run)، ثم قسم Artifacts وحمّل `Deutsch-Karten-APK`. فك ضغطه لتحصل على `app-debug.apk`.
8. افتح APK على الهاتف واسمح بالتثبيت من هذا المصدر إذا طلب Android ذلك.

ملاحظات:
- البناء يتم على خوادم GitHub، وليس محلياً داخل Termux؛ Termux يستخدم لإرسال المشروع من الهاتف.
- يلزم حساب GitHub واتصال بالإنترنت.
- هذا إصدار Debug للتجربة والتثبيت الشخصي، وليس إصداراً منشوراً على Google Play.
- يحتفظ التطبيق بالبطاقات في التخزين المحلي داخل التطبيق. احرص على عدم حذف بيانات التطبيق إذا أردت الاحتفاظ بها.
- النطق الألماني يعتمد على محرك تحويل النص إلى كلام والأصوات الألمانية المتاحة في الجهاز.
